# Hillah River System – Monitoring Network (draft showcase)

Interactive web map of the current monitoring situation, identified gaps, Phase 1 priorities and the proposed long-term monitoring network of the Hillah River system (Iraq).

**Draft for discussion.** Content and assumptions are shown in the app under *About / assumptions*. Basemaps (OpenStreetMap light grey, streets, terrain, satellite) require an internet connection.

Parameters and telemetry of the 14 proposed stations are shown on each station card (water level, discharge, velocity, pH, dissolved oxygen, electrical conductivity, temperature, turbidity - expandable to meteorological parameters; satellite telemetry, real-time, 15-minute recording / hourly transmission), confirmed 2026-09-27.

"Print / export map" (top right) saves the current map view as a PDF or PNG, in A4 or A5, portrait or landscape.

Static site (HTML, JavaScript, Leaflet, html2canvas, jsPDF) – no build step.

Updated 2026-10-18: 13 drains and extra drain attributes added to the drains layer, the Hilla-Hashimiya drainage project as a separate layer (off at start, location unverified), and an English / Arabic list of data sources under *About*.
